# Políticas de Compensación y Cierre Financiero
1. **Accruals (Provisiones):** Lo que se estimó contablemente para el cierre de mes/Q.
2. **Pagos Reales (Actuals):** Lo que efectivamente se aprueba y paga a la fuerza de ventas.
3. **Objetivo de Conciliación:** Detectar variaciones (Variance = Accrual - Actual) y explicar desviaciones.
4. **Formato:** Fórmulas masivas (BUSCARX/XLOOKUP, SUMAR.SI.CONJUNTO/SUMIFS), código M para Power Query o scripts en Python/VBA para unificar archivos dispersos.
